# Leak-guard findings that are already in pushed history (see scripts/leak-guard.sh).
#
# One line per finding: <commit, 12 hex> <sha256 of the exact finding> <reason>.
# The finding itself is never written here. A normal guard run reports these

# default branch and on every tag before anything is mirrored or released,
# refuses them. This list must therefore be empty: a finding in history is
# removed by rewriting that history before it is mirrored, not by listing it.
