# ataila_brand (Resource)

The platform's brand (a singleton): the product name, colour, page title and logo shown to every tenant and user, the sign-in page included.

The brand always exists: **create** replaces its fields with the configuration's, **update** does the same, and **destroy only removes it from the state**. Every write names the brand's `version` as last read (If-Match): when the brand changed outside the configuration after that read, the platform refuses (412) and the provider reports it; run plan again. It never retries.

Fields left out take the defaults below, not the brand's current values: the resource manages all of them. The attribution line and whether the portal is the vendor's own are read-only on the platform and not attributes here. The sidebar tagline, the sign-in texts and the footer links are not managed by the API and keep their values.

Needs the permission `brand-center-admin-global`. Import with the id `current`.

## Example Usage

```terraform
resource "ataila_brand" "this" {
  product_name        = "Example Cloud"
  product_name_accent = "Cloud"
  brand_color         = "#1e88e5"
  page_title          = "Example Cloud portal"
  logo_size           = "medium"
  logo_asset_id       = ataila_brand_asset.logo.id
}
```

## Schema

### Required

- `brand_color` (String) Six-digit hex colour, for example `#2196f3`. The platform stores it in lower case; the provider keeps the configuration's spelling.
- `page_title` (String) The browser-tab title, 1-60 characters.
- `product_name` (String) The wordmark in the sidebar and on the sign-in page, 2-32 characters.

### Optional

- `favicon_asset_id` (String) A brand asset of kind `favicon`; left out, the built-in one is kept.
- `logo_asset_id` (String) A brand asset of kind `logo` (`ataila_brand_asset`); left out, the built-in logo is shown.
- `logo_offset_x` (Number) Horizontal nudge of the logo in pixels, -40 to 40; default 0.
- `logo_size` (String) The sidebar logo size: `compact`, `medium`, `regular` (the default) or `large`.
- `product_name_accent` (String) A part of `product_name` shown in `brand_color`; empty (the default) colours the whole name. At most 32 characters.

### Read-Only

- `id` (String) Always `current`.
- `updated_at` (String) When the brand last changed: RFC 3339 in UTC, compared as an instant.
- `version` (Number) The brand's version, bumped by every change; the next write names it.

## Import

The import command is the same in both CLIs:

```shell
# The brand is a singleton. OpenTofu:
tofu import ataila_brand.this current

# Terraform:
terraform import ataila_brand.this current
```
