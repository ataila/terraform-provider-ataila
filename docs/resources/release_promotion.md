# ataila_release_promotion (Resource)

A request to promote one component of a Kubernetes project into one environment (the platform's Release Manager). It records the request; it never decides a go-live.

* `dev` deploys a named build: `version` is required, and the platform cannot check that the build exists before it dispatches.
* `uat` and `prod` promote what the environment below **last reported** running (`dev` for `uat`, `uat` for `prod`): leave `version` out to take it, or give it and it must be that version.
* `prod` is a **request that waits for a person** to approve it in the portal. With `wait_for_approval = false` (the default) create ends at once with `status = awaiting_approval` and a warning; with `true` it waits for the decision, up to `timeouts.create`.

Create waits until the operation succeeds. A failed operation (rejected, failed, or timed out on the platform) fails the apply and taints the resource, so the next apply requests again. On a platform that fakes dispatch (`dryrun`, or `simulate`) nothing is executed and the operation never completes: create then ends with the status it saw and a warning naming the mode. When `timeouts.create` passes, create ends the same way, with a warning: the operation goes on, and a refresh follows it. Tainting it would book a second deployment.

All arguments are **frozen**: a change fails the plan; declare a new resource for a new promotion. **Destroy only removes the resource from the state**: the history stays, and a pending PROD request stays pending in the portal. Import by the release operation's id (a data copy is refused).

## Example Usage

```terraform
# DEV deploys a named build.
resource "ataila_release_promotion" "api_dev" {
  project_id = ataila_project.shop.id
  component  = "app-api"
  target_env = "dev"
  version    = "1.4.0"
}

# UAT takes the version DEV last reported.
resource "ataila_release_promotion" "api_uat" {
  project_id = ataila_project.shop.id
  component  = "app-api"
  target_env = "uat"

  depends_on = [ataila_release_promotion.api_dev]
}

# PROD is a request a person approves in the portal; wait for the decision.
resource "ataila_release_promotion" "api_prod" {
  project_id        = ataila_project.shop.id
  component         = "app-api"
  target_env        = "prod"
  wait_for_approval = true

  timeouts {
    create = "4h"
  }

  depends_on = [ataila_release_promotion.api_uat]
}
```

## Schema

### Required

- `component` (String) `app-api` or `www`. **Frozen.**
- `project_id` (String) Id of the project (Kubernetes projects only). **Frozen.**
- `target_env` (String) `dev`, `uat` or `prod`. **Frozen.**

### Optional

- `timeouts` (Block, Optional) (see [below for nested schema](#nestedblock--timeouts))
- `version` (String) The version (image tag). Required for `dev`. For `uat` and `prod`, left out means the version the source environment last reported. **Frozen.**
- `wait_for_approval` (Boolean) For `prod`: wait for a person to approve or reject the request, up to `timeouts.create`. Default `false`: create ends once the request is booked.

### Read-Only

- `approval_reason` (String) The reason and the approver's note, as recorded; addresses and digests masked.
- `completed_at` (String) When it ended. RFC 3339 in UTC.
- `decided_at` (String) When it was decided. RFC 3339 in UTC.
- `decided_by` (String) Who approved or rejected it.
- `error_reason` (String) Why it failed or was rejected; addresses and digests masked.
- `id` (String) The release operation's id.
- `operation_id` (String) `release:<id>`, the operation to poll.
- `pipeline_url` (String) The pipeline carrying it out, once known.
- `portal_status` (String) The Release Manager's own status: `pending`, `approved`, `rejected`, `running`, `succeeded` or `failed`.
- `requested_at` (String) When it was requested. RFC 3339 in UTC.
- `requested_by` (String) Who asked: the token's principal.
- `requested_token_id` (String) The API token used.

- `source_env` (String) The environment promoted from (`sandbox` for `dev`).
- `started_at` (String) When it started running. RFC 3339 in UTC.
- `status` (String) `awaiting_approval` (a PROD request waiting for a person), `pending` (approved, not picked up), `running`, `succeeded` or `failed` (also when rejected, or given up on by the platform).
