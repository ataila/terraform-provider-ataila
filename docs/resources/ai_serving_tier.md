# ataila_ai_serving_tier (Resource)

The pin and the enabled flag of one serving tier of the AI gateway. Tiers exist only in the platform's catalogue: this resource manages an EXISTING tier (a key the catalogue does not have is an error) and **destroying it only forgets it**: nothing is sent, the tier keeps its last pin and flag. A pin changes what every client of the tier gets.

A `pinned_model` that is not loaded on the fleet is refused unless `allow_unloaded_pin = true`; the tier then serves nothing until that model is loaded.

## Example Usage

```terraform
# Pin the "code" tier to one served model. Destroying this only forgets it.
resource "ataila_ai_serving_tier" "code" {
  key          = "code"
  pinned_model = "model-code-large"
  enabled      = true
}
```

## Schema

### Required

- `key` (String) The tier's name, for example `code`. Changing it manages another tier (this one is forgotten).

### Optional

- `allow_unloaded_pin` (Boolean) Accept a `pinned_model` that is not loaded. Sent with each change; not read back.
- `enabled` (Boolean) Whether clients can use the tier; `false` hides it from every client. Defaults to `true`.
- `pinned_model` (String) The served model the tier is pinned to; null lets the platform auto-assign one.

### Read-Only

- `candidate_models` (List of String) Every model loaded on the fleet right now: what `pinned_model` may be without `allow_unloaded_pin`.
- `category` (String) The group the tier belongs to.
- `created_at` (String) When the tier was created: RFC 3339 in UTC, compared as an instant.
- `id` (String) The tier's key.
- `label` (String) Display name.
- `resolved` (Boolean) A loaded model backs the tier right now.
- `resolved_model` (String) The served model backing it right now.
- `role` (String) The tier's role, when it has one.
- `sort` (Number) Display order.
- `source` (String) `pin` (the pin is loaded and serves), `auto` (auto-assigned), `pin-offline` (pinned to a model that is not loaded, so the tier serves nothing) or `none`.
- `updated_at` (String) The last change to the pin or the enabled flag (the creation time until the first change): RFC 3339 in UTC, compared as an instant.
