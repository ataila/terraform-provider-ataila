# ataila_project_prod_lock (Resource)

The PROD **data** lock of a project: while it is set, the portal refuses every data copy into PROD, so PROD stays the source of truth for its data. It does not block code promotion.

Unlocking (`locked = false`) needs `confirm_unlock` set to the project's short name; it is sent only to unlock. **Destroy only removes the resource from the state**: the lock stays as it is. Import by project id.

## Example Usage

```terraform
resource "ataila_project_prod_lock" "shop" {
  project_id = ataila_project.shop.id
  locked     = true
}

# To unlock:
#   locked         = false
#   confirm_unlock = "shop"   # the project's short name
```

## Schema

### Required

- `locked` (Boolean) `true` locks PROD data; `false` unlocks it (needs `confirm_unlock`).
- `project_id` (String) Id of the project. **Frozen.**

### Optional

- `confirm_unlock` (String) The project's short name, exactly: required when `locked = false`, sent only then.

### Read-Only

- `id` (String) The project id.
- `locked_at` (String) When it was locked: RFC 3339 in UTC.
- `locked_by` (String) Who locked it.
