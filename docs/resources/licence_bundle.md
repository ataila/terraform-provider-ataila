# ataila_licence_bundle (Resource)

The licence bundle installed on the platform (a singleton).

**Create** installs the bundle, unless the platform already holds exactly this document (its `document_digest` matches the bundle's), which is adopted as it is. The platform installs a bundle only when its epoch is higher than the installed document's; an older one (409 `stale_epoch`) is an error that is not retried.

**Read** reads the licence. When the installed document is not this bundle's any more (another bundle was installed outside this configuration), the next plan shows an update of `document_digest`; applying it installs this bundle again, which the platform refuses when the installed one is newer. Nothing is ever replaced.

**Destroy only removes the resource from the state**: there is no way to remove a licence. The provider never activates, signs or reveals a licence.

Needs the permission `licence-admin-global`. Import with the id `current`.

## Example Usage

```terraform
# The bundle issued for this platform, kept next to the configuration.
resource "ataila_licence_bundle" "this" {
  bundle = trimspace(file("${path.module}/licence.acplic1"))
}

output "licence_state" {
  value = ataila_licence_bundle.this.state
}
```

## Schema

### Required

- `bundle` (String, Sensitive) The `acplic1.` bundle issued for this platform. **Sensitive.** Read it from a file, for example `file("licence.acplic1")`.

### Read-Only

- `document_digest` (String) sha256 (hex) of the installed licence document. The provider plans an update when it differs from the bundle's.
- `id` (String) Always `current`.
- `installed_at` (String) When the installed document was installed.
- `licence_epoch` (Number) The installed document's epoch.
- `licence_id` (String) The installed licence's id.
- `state` (String) The licence state, for example `ACTIVE`, `EXPIRING`, `GRACE` or `LOCKED`.
- `tier` (String) The licensed tier.
- `valid_until` (String) End of the licence term: RFC 3339 in UTC, compared as an instant.

## Import

The import command is the same in both CLIs:

```shell
# The licence is a singleton. OpenTofu:
tofu import ataila_licence_bundle.this current

# Terraform:
terraform import ataila_licence_bundle.this current
```
