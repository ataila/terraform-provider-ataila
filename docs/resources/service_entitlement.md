# ataila_service_entitlement (Resource)

A service a customer holds (an entitlement): the commercial gate a person's `ataila_service_grant` needs. Needs a token holding `entitlements-admin-global` and platform release 1.0.392 or later.

**The provider never approves.** For a service that needs approval (`requires_approval` on `ataila_services`), `state = "enabled"` is stored as `pending_approval` (`effective_state`) with a warning, and no grant under it is in force until an operator approves it in the portal. The configuration still shows no difference; an approval given in the portal is kept on every apply.

Creating an entitlement the customer already holds adopts it (a warning says so). Changing `customer_id` or `service_key` replaces it. **Destroy withdraws the service**: the entitlement is disabled and every grant under it is revoked, so re-creating it gives nobody access back. It is destroy-class: it needs `allow_destroy = true` in the provider and a token created with destroy allowed.

## Example Usage

```terraform
# The customer holds Coder for up to ten people.
resource "ataila_service_entitlement" "coder" {
  customer_id = ataila_customer.example.id
  service_key = "coder"
  seats       = 10
}
```

## Schema

### Required

- `customer_id` (String) Id of the customer. Changing it replaces the entitlement.
- `service_key` (String) The service's key (`key` on `ataila_services`). Changing it replaces the entitlement.

### Optional

- `dedicated_url` (String) The customer's own instance of a `dedicated` service.
- `notes` (String) Free text.
- `seats` (Number) How many people may hold a grant under it at once; leave it out for no limit.
- `state` (String) `enabled` (the default) or `disabled`. Disabling keeps the grants under it (none is in force while it is disabled; enabling it again brings them back); destroying revokes them.

### Read-Only

- `approved` (Boolean) An operator approved the entitlement in the portal.
- `approved_at` (String) When it was approved: RFC 3339 in UTC; null when not.
- `created_at` (String) When the customer first held the service: RFC 3339 in UTC.
- `effective_state` (String) What the platform stored: `enabled`, `pending_approval` (waiting for an operator's approval in the portal) or `disabled`.
- `id` (String) `<customer_id>/<service_key>`.
- `seats_used` (Number) How many people hold an unrevoked grant under it.
- `service_name` (String) The service's display name.
- `updated_at` (String) When the entitlement last changed: RFC 3339 in UTC.
- `url` (String) Where the customer uses the service: `dedicated_url` when set, else the service's own address.

## Import

The import command is the same in both CLIs:

```shell
# <customer_id>/<service_key>. OpenTofu:
tofu import ataila_service_entitlement.coder 12/coder

# Terraform:
terraform import ataila_service_entitlement.coder 12/coder
```
