# ataila_brand_app (Resource)

One application's Brand Center profile: the name, colours, logo, font, footer and legal links an application built on the platform shows, overriding this platform's own brand field by field.

Every field is optional, and a field left out is **inherited**: the application shows this platform's brand (or the built-in default) for it. The resource manages all of them: a write replaces the whole profile, so a field set in the portal and left out here goes back to inherited on the next apply. Every update names the profile's `version` as last read (If-Match): when the profile changed outside the configuration after that read, the platform refuses (412) and the provider reports it; run plan again. It never retries.

**Create refuses an application that already has a profile** (one made in the portal, say): import it instead, so that nothing is overwritten unseen. **Destroy deletes the profile**: the application inherits everything again; its uploaded assets are kept.

Needs the permission `brand-center-admin-global` and platform release 1.0.305 or later. Import with the application slug.

## Example Usage

```terraform
# The brand of an application built on the platform. Fields left out are
# inherited from the platform's own brand.
resource "ataila_brand_app" "shop" {
  app_slug             = "shop"
  display_name         = "Example Shop"
  display_name_accent  = "Shop"
  primary_color        = "#0b6e4f"
  header_logo_asset_id = ataila_brand_asset.shop_logo.id
  default_language     = "en"
  legal_privacy_url    = "https://shop.example.com/privacy"

  footer_links = [
    { label = "Privacy", url = "https://shop.example.com/privacy" },
    { label = "Contact", url = "https://shop.example.com/contact" },
  ]
}
```

## Schema

### Required

- `app_slug` (String) The application: lower-case letters, digits and hyphens, starting with a letter, 2-32 characters. Changing it replaces the resource.

### Optional

- `co_brand_line_en` (String) An optional partner line in the footer, in English, at most 120 characters. Left out: inherited.
- `co_brand_line_hu` (String) An optional partner line in the footer, in Hungarian, at most 120 characters. Left out: inherited.
- `default_language` (String) The language a first-time visitor sees: `en` or `hu`. Left out: inherited.
- `display_name` (String) The application's name in its header, 2-32 characters. Left out: inherited.
- `display_name_accent` (String) A part of `display_name` rendered in the primary colour; `""` colours the whole name. Needs `display_name`, at most 32 characters. Left out: inherited.
- `favicon_asset_id` (String) A brand asset of kind `favicon`. Left out: inherited.
- `font_preset` (String) `inter`, `montserrat` or `system`. Left out: inherited.
- `footer_links` (Attributes List) Up to five footer links. `[]`: no links. Left out: inherited. (see [below for nested schema](#nestedatt--footer_links))
- `footer_text_en` (String) The footer line in English, at most 160 characters. Left out: inherited.
- `footer_text_hu` (String) The footer line in Hungarian, at most 160 characters. Left out: inherited.
- `header_logo_asset_id` (String) A brand asset of kind `header_logo` or `logo` (`ataila_brand_asset`). Left out: inherited.
- `header_logo_size` (String) `compact`, `medium`, `regular` or `large`. Left out: inherited.
- `legal_imprint_url` (String) The imprint (legal notice); starts with `https://`, at most 300 characters. Left out: inherited.
- `legal_privacy_url` (String) The privacy notice; starts with `https://`, at most 300 characters. Left out: inherited.
- `og_image_asset_id` (String) A brand asset of kind `og_image` (the social preview card, 1200 x 630). Left out: inherited.
- `on_primary_color` (String) Lower-case six-digit hex text colour on the primary (button text), used in place of the computed one. Left out: inherited.
- `primary_color` (String) Lower-case six-digit hex colour, for example `#0b6e4f`. Left out: inherited.
- `secondary_color` (String) Lower-case six-digit hex highlight colour. Left out: inherited.

### Read-Only

- `updated_at` (String) When the profile last changed: RFC 3339 in UTC, compared as an instant.
- `version` (Number) The profile's version, bumped by every change; the next write names it.

The import command is the same in both CLIs:

