# ataila_project_backup_plan (Resource)

A project's backup plan: whether the project is backed up, what each environment's sets carry, and the tiers (how often, how many kept). Every project has a plan: a new one gets the default (enabled; DEV code and database; PROD code, database and files; UAT none; the installation's default tiers).

**Creating** this resource takes the project's plan over and replaces it with the configuration. Leaving `environments` out means the default environments; leaving `tiers` out follows the installation's default tiers, which then apply as they change (Settings › Backups). Setting `tiers` gives the project its own, even when they equal the default.

**`enabled = false`** stops every scheduled set and is destroy-class: it needs `allow_destroy = true` on the provider **and** a token created with destroy allowed. **Destroy** returns the plan to the default, which never switches backups off and needs neither; the plan itself is never removed. On a retired project destroy changes nothing.

Back up now, exports and restores are requested in the portal, never here. Needs `project-backup-admin-global` (the read key reads); platform release 1.0.399 or later.

## Example Usage

```terraform
# The default plan, declared: enabled, the default environments, and the
# installation's default tiers followed as they change.
resource "ataila_project_backup_plan" "shop" {
  project_id = ataila_project.shop.id
}

# UAT's database backed up too, and the project's own tiers.
resource "ataila_project_backup_plan" "ledger" {
  project_id = ataila_project.ledger.id

  environments = {
    dev  = { code = true, database = true, files = false }
    uat  = { code = false, database = true, files = false }
    prod = { code = true, database = true, files = true }
  }

  tiers = {
    daily   = { keep = 14, at = "01:30" }
    weekly  = { keep = 8, day = "sun" }
    monthly = { keep = 12, day = 1 }
    yearly  = { keep = 7 }
  }
}
```

## Schema

### Required

- `project_id` (String) Id of the project. Changing it replaces the resource: the old project's plan returns to the default.

### Optional

- `enabled` (Boolean) Whether the project is backed up; true when left out. `false` stops every scheduled set (those already made are kept until they expire) and is destroy-class.
- `environments` (Attributes) What each environment's sets carry. Left out: the default (DEV code and database, PROD all three, UAT none). An environment with nothing is not backed up; one that is not deployed is skipped whatever it says. (see [below for nested schema](#nestedatt--environments))
- `tiers` (Attributes) The project's own tiers. Left out, the plan follows the installation's default tiers. A set made by one tier counts against that tier's `keep` only. (see [below for nested schema](#nestedatt--tiers))

### Read-Only

- `id` (String) The project's id, as `project_id`.
- `is_default` (Boolean) True while the plan is the default: enabled, the default environments and the installation's default tiers followed.
- `tiers_overridden` (Boolean) True when the project has its own tiers (`tiers` set).
- `version` (Number) The plan's version on the platform, bumped by every change from the portal or the API. The provider replaces the plan only at the version it last read.
