# ataila_service_grant (Resource)

A person's grant of a service under one customer. It is in force (`effective`) only while the customer's `ataila_service_entitlement` is enabled and approved, the service is offered and the grant is not revoked; `blocked_by` says why not. The person's access in the service follows within the platform's reconcile interval. Needs a token holding `entitlements-admin-global` and platform release 1.0.392 or later.

The customer must hold the service and have a free seat; the person must belong to the customer (a tenant membership or a project role). Creating a grant the person already holds adopts it (a warning says so); a revoked grant is revived. A grant revoked outside the configuration is gone, and the next plan creates it again. **Destroy revokes the grant**: the row is kept, with its revocation. It is destroy-class: it needs `allow_destroy = true` in the provider and a token created with destroy allowed.

## Example Usage

```terraform
variable "developer_user_id" {
  description = "Id of a platform user who belongs to the customer, as the portal shows it."
  type        = string
}

# The developer may use Coder under the customer's entitlement.
resource "ataila_service_grant" "developer_coder" {
  user_id     = var.developer_user_id
  customer_id = ataila_service_entitlement.coder.customer_id
  service_key = ataila_service_entitlement.coder.service_key
  grant_level = "user"
}
```

## Schema

### Required

- `customer_id` (String) Id of the customer the grant is held under. Changing it replaces the grant.
- `service_key` (String) The service's key. Changing it replaces the grant.
- `user_id` (String) Id of the person. Changing it replaces the grant.

### Optional

- `grant_level` (String) What the person may do in the service: `login`, `user` (the default), `admin` or `audit`.
- `notes` (String) Free text.

### Read-Only

- `blocked_by` (String) Why the grant is not in force (`service_retired`, `customer_pending_approval`, `customer_disabled`); null when it is.
- `effective` (Boolean) The grant is in force right now.
- `granted_at` (String) When it was granted: RFC 3339 in UTC.
- `granted_by` (String) Who granted it (a user id), when recorded.
- `id` (String) `<user_id>/<customer_id>/<service_key>`.
- `user_email` (String) The person's e-mail address.
