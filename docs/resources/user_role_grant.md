# ataila_user_role_grant (Resource)

One role held by one user. Grants are additive: this resource adds or removes its own role and leaves the others alone. Changing `user_id` or `role` replaces the grant, which is safe. Destroying removes the role and needs no `allow_destroy`.

Granting a role the user already holds adopts it (a warning says so). An API token can never grant or revoke `admin`, `founder` or `ssh-console`, never change its own account's roles, and grants or revokes only roles it carries itself; each is a clear error, never retried. The platform also keeps at least one role per user and one active admin.

## Example Usage

```terraform
# One role for one person. The token applying this must itself carry the role.
resource "ataila_user_role_grant" "dana_reads_users" {
  user_id = ataila_user.dana.id
  role    = "users-read-global"
}
```

## Schema

### Required

- `role` (String) A role name from the roles catalogue: a permission key (see `ataila_permission_catalog`, `grantable`) or a role such as `user`. Changing it replaces the grant.
- `user_id` (String) Id of the user. Changing it replaces the grant.

### Read-Only

- `granted_at` (String) When the role was granted, when the platform knows it: RFC 3339 in UTC.
- `id` (String) `<user_id>/<role>`.
